プライバシーについて

最終更新日：2026年11月1日

このゲームは、個人情報を入力させずに遊べることを基本方針としています。以下は現在の実装と配信方式に基づく説明です。通信・ホスティング事業者側の処理を含め、あらゆるデータ処理がゼロであることを保証するものではありません。

ゲームが要求しない情報

ゲーム機能として、アカウント登録、ログイン、本名、メールアドレス、電話番号、住所、位置情報、連絡先帳、SNS連携、広告IDを要求しない設計です。個人を長期間追跡するプレイヤーIDも導入しません。

端末内の保存

セーブデータや設定は、ゲームの動作に必要な範囲でブラウザの端末内ストレージに保存されます。ブラウザのデータ消去や端末変更により、保存内容が失われることがあります。共有端末を使う場合は、端末内にゲームデータが残る可能性に注意してください。

通信とホスティング

ゲームは同一サイト内のページ・ファイルを読み込み、バージョン確認のために同一サイトの version.json を確認します。オンライン対戦サーバー、アカウント、フレンド同期、クラウドセーブは接続されていません。

このサイトは GitHub Pages で配信されています。GitHub は GitHub Pages の訪問者について、サービスの安全性・完全性を保つ目的で、IP アドレスを含む技術情報やアクセスログを収集する場合があると説明しています。ページを見ただけでゲーム運営者にそのログが渡るわけではありませんが、運営者は GitHub 側の個別ログを閲覧・削除したり、保存期間を指定したりできません。保存期間は公開資料から一律には確認できません。詳細は GitHub のプライバシー声明 を確認してください。

第三者提供・広告・解析

ゲームの機能として広告SDKやアクセス解析SDKを追加しない方針です。配信基盤やブラウザが行う処理については、上記のとおりゲーム本体から制御できない場合があります。

データの削除

端末内のセーブデータは、ゲームで使ったブラウザのサイトデータを消去することで削除できます。ただし、削除操作により他の保存設定も失われる場合があります。ホスティング事業者側の技術ログについては、運営者がこのゲーム画面から個別に削除できるとは限りません。

今後の変更

オンライン対戦などの通信機能を追加する場合は、接続先、送受信するデータ、保存期間、削除方法、第三者による処理を再確認し、説明とテストを更新するまで有効化しません。アカウントや個人情報を必要とする機能は追加しません。

確認上の限界：この説明はコードと構成の確認に基づきます。ホスティング事業者側のログ設定や、すべての端末・ブラウザの挙動を独立に検証した結果ではありません。

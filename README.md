# 歴史戦略 — 分岐する年代記

ブラウザで遊べる、歴史の分岐をテーマにしたターン制ストラテジーの試作版です。

## 起動方法
- `index.html` をダウンロードしてブラウザで開くと遊べます。
- GitHub Pagesを有効にすれば、ウェブサイトとして公開できます。
- ビルドツールや外部ライブラリは不要です。

## 実装済みの基本機能
- 妨害派と史実派の2陣営
- CPU対戦とCPU難易度設定
- 同じ端末で交互に操作する2人対戦
- 6地域のマップ、地域支配、兵力、資金、食料、開発レベル
- 兵力増強、地域開発、外交交渉、歴史工作、史実保護、地域への攻勢
- ターン進行、年代記イベント、歴史点、勝利判定、行動ログ
- スマートフォン画面に対応するレイアウト

## 未実装・注意事項
- **オンライン対戦は未実装です。** インターネット越しに知らない人と対戦するには、認証・マッチング・リアルタイム同期・切断処理を行うバックエンドが必要です。
- セーブ／ロード、ルーム作成、ランキングも未実装です。
- 現在はプロトタイプです。勝利条件やCPUの戦略は今後テスト・調整が必要です。
- 進行状況は保存されず、ページを再読み込みするとリセットされます。

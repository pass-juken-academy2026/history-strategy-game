# 歴史戦略 — 分岐する年代記

歴史の分岐をテーマにした、ブラウザ向けターン制ストラテジーゲームです。

## 新しい試作モード：神の視点・歴史コース

- [神の視点・歴史コースを開く](./timeline.html)：古代から現代へ流れる立体風の歴史コースを俯瞰し、時代ごとにブロックを配置する試作ページです。
- **分岐モード**は妨害ブロックのみ。史実派の対抗アクションは登場しません。
- **対戦モード**だけが「妨害派 vs 史実派」の構成で、史実派CPUは史料・教育・対話などの保護ブロックを使います。
- 3D画面はThree.jsによるリアルタイム描画です。カメラは回転・ズームでき、ブロックは選択して配置し、配置後にドラッグ移動・キーボードの `+` / `-` でサイズ変更できます。時間は自動進行／手動進行を切り替えられます。
- 3D試作には端末内の5スロット保存・読み込みがあり、配置ブロックの位置とサイズも保存します。ログインや連絡先は不要です。
- **画質について**：現段階はコード生成の地形・建物を中心とした3D試作です。参考画像級の写実的な品質、精細なライセンス確認済みモデルの全投入、全時代の歴史イベント網羅、実機性能調整は未完了です。Three.js CDNを読み込むため初回起動時にインターネット接続が必要です。
- 分岐モードは妨害ブロックのみ、対戦モードは妨害派vs史実派CPUです。オンライン対戦・フレンド招待は未実装で、現状の対戦はローカル試作です。

## 現在の機能
- 妨害派と史実派の2陣営
- CPU対戦（初級・標準・上級）と同じ端末での2人対戦
- 27地域のマクロ地域マップ、地域支配、兵力、資金、食料、開発レベル（開発上限レベル5）
- 兵力増強、地域開発、外交交渉、歴史工作、史実保護、地域への攻勢
- ターン進行、年代記イベント、歴史点、勝利判定、行動ログ
- スマートフォン向けレイアウト
- 神の視点3D試作ページでは、自動進行（12秒ごと）と手動進行を切替可能
- 3Dコースの状態・資源・選択モード・配置ブロックを端末内のlocalStorageへ自動保存し、再開時に復元（ログイン・氏名・メールアドレスは要求しない）
- 設定ボタンから端末内セーブを削除可能。保存領域を利用できない環境では保存が失敗する場合がある
- オンライン対戦は未実装。匿名招待方式を検討できるが、通信サーバーではIPアドレス等が処理される可能性があり、個人情報を一切扱わないとは現時点で保証できない
- 3D描画はThree.js CDNを読み込むため、初回起動時はインターネット接続が必要。端末・GPU性能により描画品質や滑らかさが異なる
- キャンペーン開始地域によってマップ名・初期資源・初期支配を変更（27地域を扱う抽象マップ。正確な国境・地理データに基づく世界地図ではありません）
- 端末内の自動セーブと保存データからの再開
- PWA manifest、Service Worker、バージョン確認と更新案内
- Node.jsによる構文・スモークテスト
- テスト成功後にGitHub Pagesへ公開するGitHub Actionsワークフロー
- CapacitorでAndroidプロジェクトを生成し、AAB候補を作るワークフロー

## ブラウザで起動
`index.html` をブラウザで開いて遊べます。PWAのインストールやService WorkerはHTTPSで配信した場合に利用できます。

## テスト
Node.js 22以降を用意し、次を実行します。

```sh
npm run check
npm test
```

## Androidビルド候補
Node.js、Java 21、Android SDKを用意し、次を実行します。

```sh
npm install
npm run android:init
cd android
./gradlew bundleRelease
```

この成果物は公開前の候補です。Google Playへ提出するには、実機テスト、正式な署名済みAAB、プライバシーポリシーの公開、Play Consoleの各申告・審査が別途必要です。リポジトリのGitHub Actionsワークフローは、現状では**署名していないAAB候補**を作成します。
